## FileRenamer </br>
```This Tool Can Not Only Rename Files In Bulk, But It Can Translate File Names```</br>

---
The purpose behind this was that we downloaded compressed files (.zip | .rar) off a foreign website and couldn't read the labels of the files we 
saved because they were in German. So we created this little tool and it helped us translate the file names for both the compressed files and 
the files that we extracted from them.
